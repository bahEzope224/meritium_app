# 🎯 Meritium - Plateforme de Recrutement Équitable

## Description
Meritium est une plateforme de recrutement qui élimine les biais discriminatoires en anonymisant les candidatures. Seules les compétences et qualifications sont visibles jusqu'à validation mutuelle.
